# 按原图重做默认形象

用户否定 v2 的相似度后，明确选择原截图右侧的**写实肌肉蓝西装**方向。旧通用人体与程序化黄色角色不再作为设计终稿；其协议检查不能代替外观验收。

2026-10-21 校正：用户再次指出 Unity v3 的头部失真、头身比错误和拼接感。三张满意的全身参考已按附件原文件 SHA 核对一致。此前分段头颈缩放方案未通过视觉验收，已替换。实测发现原生重建头部本身也有颅顶过高、眼下脸偏短的问题：统一缩放与姿态校正后，顶→眼仍占头高约 63%，参考约 50–53%。本轮以实际眼、眉、下颏位置驱动平滑局部修形，并独立校正颈根、几何切向和皮肤过渡。源网格不被视为正确比例的真值，技术检查也不代表用户已确认相似度。

用户建议的桌面 Blender 已找到并验证为 5.2.1 LTS，已实际执行修模、渲染和 FBX 导出，并打开打包贴图、并列参考图的可编辑工程。流程及工具评估见 [Blender → Unity 工作流](blender-unity-workflow.md)。当前在本地 Blender 中修正默认造型，DeepSeek 的用途保持为运行时意图解析。

本轮生产资源标识为 `blender-landmark-neck-fit-v3`。同一头部原型用于三套服装：头顶到下颏约 0.239 m，占 1.85 m 身高的 12.91%；顶到眼占头高 52.32%。这些是三维模型的测量值；参考图的二维比例带有姿态与透视误差，不能据此声称已逐像素复刻。

颈部前切线位于 1.59 m、后发际切线位于 1.665 m；新桥接面按原颈面切向平滑接入。西装前接缝的面法线夹角中位数从约 71° 降到 8.18°，运动服为 8.54°，裸上身为 5.61°。三套均没有桥接开边或零面积面，导出网格不带遗留 custom split normals。衣领边界平滑最大位移为 2.5 mm；裸上身前颈另按实际头部表面收进。

裸身接合曾出现明显过宽的侧颈：1.62 m 高度处约 22.3 cm，而原身体颈部约 16.6 cm。现按原身体曲面约束桥接内部顶点，生产网格最大径向回收约 26.8 mm；上、下接合边界保持连续。后侧原切圈的一处锯齿回折曾形成黑缝，已在局部 6 mm 位移范围内平滑，并向邻近两圈衰减。侧面实际渲染确认黑缝消失。具体生产参数与指纹在 `StudyData/avatar-v3/unity-blender-staging/AvatarDemo/assembly.json` 和 `production-resource-install.json`。

帽子按两个人物的实际顶部截面拟合；黄色角色眼镜贴合面部，镜框高度覆盖眼睛，鼻梁连接点随镜框宽度计算，修复之前悬空的短桥。

新增的裸身三分之四视图暴露出左腰侧蓝紫斑块。逐点射线与 UV 采样确认它来自原 GLB 的 albedo，部分像素被换色遮罩保留、部分随短裤变色。`repair_bare_texture.py` 在复制的贴图上按实际模型坐标取对侧皮肤采样；对侧采样也受污染时，改用同侧邻近干净皮肤。共修复 6398 个像素（全图 4194304 像素），限定区域内跳过的蓝紫像素为 0，其余 albedo 像素保持不变；重新生成遮罩后，已检查的污染点均为肤色且 mask=0。原 GLB、几何、UV、头部及其他服装贴图保持不变。纹理修订为 `blender-bare-skin-cleanup-v2`；采样证据见 `StudyData/avatar-v3/texture-cleanup-validation.json`。

当前仍有可见细节限制：头发重建偏块状，后发际较平；裸身前颈根留有约 1–2 mm 的原网格小齿，后肩接合在 Unity 侧面光照中仍有短暗折痕；衣领纹理和手部细节尚不及二维参考的精细程度。没有将这些问题写成已解决或将本轮工程检查写成用户视觉验收。

## 已确定的外观

男性：原图所示的成熟、棱角分明的脸；短而凌乱、向额前垂落的黑色碎发；细矩形金属眼镜；厚实胸肌与圆肩撑起深宝蓝西装；收腰；无领带白衬衣；同色西裤和黑皮鞋。不能只给普通人体加宽肩膀，不能用向后梳高的发型或无辨识度的默认脸。

黄色角色：原图所示的圆钝头、短突出嘴部、小型绿色眼睛、大而低的圆腹、浅色腹部、抱腹短臂、粗短腿及较长扁平三趾脚。不能把它改成尖头、大蛙眼、长细小腿或球形小脚。

原图优先于生成参考。新参考用于补足完整身体和近距离脸部，背面等未提供的内容属于建模推断。默认形象由本任务设计、制作与检查；DeepSeek 继续只处理运行时用户修改意图，不参与造型生成。

## 资产路线与验收

五份带 UV 和 2048² 贴图的真实三维资源已经在台式机完成：西装人体、独立高细节头部、运动服人体、裸上身与短裤人体，以及完整黄色角色。原始输出、输入指纹和重建记录在 `StudyData/avatar-v3/generated/`，详见 [重建记录](avatar-v3-reconstruction.md)。这些资产由本任务使用本地 Hunyuan3D-2 重建，DeepSeek 不参与造型。

`assemble_reference_avatars.py` 将三套服装接上同一头部，按每套衣领生成连续颈部，制作可拆卸眼镜和帽子，并统一朝向、米制尺寸和足底位置。眼镜按实际鼻梁、左右脸颊及耳廓贴合。衣料和黄色身体使用独立颜色遮罩，白衬衣、皮肤、鞋、浅色腹部和脚保留原色。

当前是用于外形编辑的静态三维角色，支持换装、颜色、配饰、整体比例、全角色替换和撤销；没有完整人体追踪或表情骨骼。用户要求的 default 由本任务负责设计，不能用通用人体或概念 PNG 代替实际模型。

`AppearanceAvatarDemoChecks` 保存七组真实 Unity 状态及额外近景、侧面视图；`AppearanceReferenceTintChecks` 检查真实 GPU 上的换色、遮罩和光照。渲染检查与用户相似度反馈是不同证据，不能将技术检查通过写成用户已验收。

新能力继续通过 debug 的 `avatar-demo-v1` 显式启用，不修改冻结正式实验的 `study-v1`。用户已选择稍后连接 PICO，新资产的设备性能、6DoF 和现场外观确认待连接后进行。录像使用台式机真实 Unity 窗口，字幕为英文。
