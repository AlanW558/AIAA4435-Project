## 目标

- 默认：参考图所示的黑短发、矩形眼镜、宽肩肌肉、蓝西装男性形象（用户称梁文锋肌肉形象）。这是参考驱动的风格化模型，不宣称本人扫描或官方模型。
- 整体替换：参考图所示的黄色圆肚奶龙，保留绿色眼睛、浅色腹部、短四肢和三趾轮廓。
- 人形的西装、运动装、肌肉上身/训练短裤是独立服装组；颜色、配饰、整体比例可独立修改。奶龙颜色作用于主体，服装值为 none。
- 使用真正的三维网格、材质与动画；用户提供 anatomy 技能，参考其部件清单、空间连接和近距离细节检查方法。

## 协议与研究边界

debug 专用 capability_profile=avatar-demo-v1，新增 avatar_id 与 outfit，默认 liang / suit / blue / glasses / 1.0。旧 study-v1 的三字段协议、冻结任务及问卷保持原意。两种 profile 的演示/实验记录必须区分，不能混入既有正式研究数据。

“全部替换为奶龙”是可撤销的原子变更：nailong / none / yellow / none / 1.0；明确要求保留的颜色、配饰或比例优先遵从。不含换人意图的颜色/服装请求不能改变 avatar_id。非法形象/服装组合须拒绝，不能隐式连带修改。

旧角色保留在 study-v1，新的两套网格仅由 demo profile 启用。所有修改仍经共享请求、候选、澄清、执行、renderer ack 和撤销路径；观察值来自实际启用的对象/材质/比例。

## 资产结构

人形拆分：基础身体、脸、独立眼球、眉毛、短发、眼镜、西装外套、衬衫/领口、长裤、鞋、运动上装、训练短裤、帽子。优先使用可核对许可证的 MakeHuman 基础网格与服装，再按参考塑形与着色。奶龙为独立的平滑连续主体、腹部、眼球、眼睑、嘴、手臂、手指、脚趾、尾巴组件。

源码、资产来源和构建配方保存在项目目录。原始用户图片留在 StudyData/avatar-v2/references，避免自动打入 APK。

1. 在实际 Unity 中检查默认、换装、改色、缩放、奶龙整体替换与撤销；记录实际 mesh/triangle 数与画面。
2. 运行受影响的后端及 Unity 检查，确认 study-v1 不接受新 demo 状态。
3. 构建桌面演示和待安装 PICO APK。用户已选择先开发、稍后连接 PICO；当前不宣称新版本已通过头显验证。
4. 新版一分钟演示保持英文字幕，使用台式机真实运行画面；保留旧成片与原始录制。
