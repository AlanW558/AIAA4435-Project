## 官方功能说明与限制

| 功能 | 官方说明 | 本项目验收边界 |
|---|---|---|
| 普通跳题与题目关联 | 免费版支持两者；跳题可到问卷末尾，并可配合筛选规则甄别人群。[版本区别](https://www.wjx.cn/app/themehtml/plan.aspx)、[跳题逻辑](https://www.wjx.cn/help/help.aspx?helpid=218) | 没有找到“跳到末尾即不保存”的官方保证，不能据此通过拒绝路径验收。 |
| 甄别页 | 点下一页时应用无效答卷筛选规则，不符合即终止。免费版不支持筛选规则，企业标准版支持 3 字段。[甄别页](https://www.wjx.cn/help/help.aspx?helpid=186)、[功能收费表](https://www.wjx.cn/help/help.aspx?h=1&helpid=875) | 终止并判无效不等于不记录。甄别页本身是否免费，未独立证实。 |
| 专用知情同意书 | 点击不同意会提交为无效答卷，后台仍可查看；入口为编辑页→调研题型→知情同意书。[官方说明](https://www.wjx.cn/help/help.aspx?helpid=594) | 明确不能作为“不保存”的实现。帮助页归属标准版服务，但未提供该题型的完整版本权限矩阵。 |
| 普通删除／标记无效 | 删除后仍可从无效答卷恢复。[删除答卷](https://www.wjx.cn/help/help.aspx?helpid=220) | 不能以普通删除证明从未保存或彻底清除。 |
| 重复填写限制 | 设备和 IP 限制位于设计问卷→问卷设置→权限设置→答题者作答次数限制；微信限制另在发放问卷→微信发送。[设置入口](https://www.wjx.cn/Help/Help.aspx?helpid=280) | 22 人共用同一设备填写全部三表，三表均应关闭设备、IP、账号／微信的次数限制。免费版表中“限制 1 次”描述防重功能，不足以证明平台强制限一次。 |
| 加载上次答案 | 断点续答可附带自动加载上次提交内容。[官方说明](https://www.wjx.cn/help/help.aspx?helpid=303) | 三表均应关闭自动回填、自动加载上次答案与断点续答，防止带入上一人或上一轮的数据。 |

**“不同意后结束且不保存回答”尚未满足／未证实。** 当前证据不支持把普通跳题、甄别页、专用知情同意书或事后普通删除视为零保存方案。保持草稿状态，并在实际设置记录中明确这一限制。
