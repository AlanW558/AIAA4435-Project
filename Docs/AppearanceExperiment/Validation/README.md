# Validation evidence

`avatar-v3/` contains the final actual Unity renders, state/geometry checks,
production resource hashes and delivery verification. Its comparison page links
to the committed reference images and editable Blender project.

WJX JSON files are dated snapshots of questionnaire structure, options, preview
logic and publication status. They do not contain participant answer rows.
Historical receipts refer to local `wjx-*.jpg` management screenshots; these
images are deliberately not included in the public checkout. The public QR code
and its decoded target remain in `Study/survey/` and the midterm verification.

The 15-response paper-transcription analysis is under
[`../Results/2026-10-21/`](../Results/2026-10-21/问卷结果与完整分析.md).
