## 1. 实现范围

后端执行字段现在包括 speech_rate、reply_length、tone、voice。四项可以单独修改或在同一请求中一起修改，完整校验后原子提交；包含尚未接通外观的请求仍不部分执行。自然语言、E/A/N/S、澄清、直接设置、单次覆盖、修改历史及局部撤销使用同一执行路径。

| 项目 | 规则与当前效果 |
| --- | --- |
| Speech rate | 0.70–1.30，精度 0.01；1.00 是所选声音下模型默认速度的倍率。当前阶段只保存参数，不保证具体提供商已支持或实际音频达到该速度 |
| Voice | voice_a / voice_b / voice_c；明确 ID 可以选择、恢复、撤销。仍未绑定音源，不宣称 B 温暖或 C 低沉 |
| 持续设置 | 当前分支内持续生效；不跨分支，也不自动带入下一题 |
| 单次设置 | 可独立或与 Tone/Reply length 组合，绑定下一条回答的完整设置快照；持久设置不变 |
| 历史与恢复 | 修改记录保存前后值与来源；指定属性撤销保留无关新变化；自然语言历史恢复由公开历史提供依据 |
| 默认恢复 | 语速恢复 1.00，Voice 恢复 voice_a，其他属性保持；默认值不等于本题起点或最近历史值 |
| 声音切换 | 保留当前 rate 倍率和其他属性，不自动回到 1.00；不假设不同声音在默认倍率具有相同真实速度 |

## 2. 数值计算与失败处理

仍由模型识别基准和操作、程序执行 Decimal 运算。首次请求使用共同起点，后续修复使用该分支的公开状态。已规范化的候选用于确认和执行，重试/重放不会重新乘一次倍率。

当前速度为 1.20 时：

| 请求含义 | 表达式 | 结果 |
| --- | --- | --- |
| 默认速度的 90% | default × 0.90 | 0.90 |
| 当前速度降低 10% | current × 0.90 | 1.08 |
| 倍率减少 0.10 | current + (-0.10) | 1.10 |

新增 RateLimitError 区分“合法数值意图超出能力”和“模型结构错误”。例如当前 1.15 的 95% 为 1.0925，无法以 0.01 精度表示；解释器现在把整个请求规范化为 supported=false，提供范围/精度说明并保留全部设置，不截断或取整。即使另一个候选合法，或同一请求中的 Voice/Tone 可执行，也不丢弃不合法部分后只执行剩余内容。

四策略对这种共同不支持请求都返回 unresolved，不额外调用 N，也不制造无法执行的确认选项。参与者可重新提出支持的数值。自由文本澄清遇到该问题时保留原问题，显示限制并允许再次回答或取消。

非法模型结构、布尔值、非有限数、未知基准/操作仍按 ModelError 处理，不能把所有模型错误伪装成用户数值限制。后端直接 `/settings` 仅接受已解析的绝对值，非法值返回 400；相对表达式由自然语言解释路径解析，不在控件接口暗中计算。

版本：`tutor-interpretation-v3`、`tutor-comparison-execution-v4`。文字生成仍为 `tutor-answer-v4`，策略仍为 `tutor-gates-v2`，本步未改变 Selective 的 0.05 工程阈值。

## 3. 回答快照、文字复用与无音频边界

- 纯参数请求可以只更新设置；混合请求更新设置后继续生成知识回答。
- 单次 speech_rate/voice 覆盖进入 job 的 settings；成功回答的 response 和 conversation 记录同一份快照。生成失败重试仍使用原快照；后来的持久设置不能重标记旧回答。
- 下一条问题恢复持久参数；新单次请求替换未绑定的覆盖，持久修改或撤销清除未绑定覆盖，保持既有作用域规则。
- speech_rate 和 voice 不影响文字生成上下文；同一题、相同问题、Tone、Reply length 及对话历史仍可复用同一份文字。每个分支分别保存其语音参数，复用文字不意味着复用未来音频。
- 将来 TTS 缓存必须包括实际声音、语速、风格及提供商等参数，不能直接复用文字缓存键；本步没有实现或模拟音频缓存。
- 单会话与比较视图新增 `audio_available: false`；单会话生成 response 带 `audio_status: "not_connected"`。语音参数修改/撤销的确认明确提示音频未接通。这些是公共能力状态，不暴露隐藏分支的结果。
- 工程 outcome=completed 只说明参数操作/文字流程完成，不证明试听或研究目标达成；正式研究仍依赖真实呈现后的参与者问卷。

首次结果仍统一开放。先完成的分支新参数不会通过结果视图提前显示；澄清题中的候选值属于供选择的信息。不同分支的自由表述答案互不复制，首次快照固定，展示后修复不覆盖首次结果。
