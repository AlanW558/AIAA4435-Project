- 新网页问卷为 `attribute-summary-feedback-v3`，策略偏好可选择 1–4 项 E/A/N/S；`No preference` 与策略选项互斥。偏好题不再提供 Unable to judge。
- Unity／后端偏好契约为 `strategy-preference-v2`，支持保存、恢复和导出多选；历史版本保持可读，不将旧单选记录假装成新问卷。
