> **2026-11-17 后续状态：** 新版已完成部分本机人工麦克风转写、试听/播放、问卷保存/下一题、暂停/继续及口述备注确认；头显整体测试仍待完成。下文按原阶段保留验收范围，最新使用入口见[导航](README.md)。

## 范围及结论

本轮真实调用现有 Qwen ASR/TTS，使用明确标记的本机合成英文作为输入，不启动麦克风、不录制参与者声音。Unity 使用现有 TutorSpeechInput 的转写、复核和确认提交路径，以及现有 WAV 解码器。自动脚本执行确认动作不代表参与者真实评价。

策略解释、澄清与 tutor 文本回答使用固定 fixture，未新增 DeepSeek 调用。本轮验证的是语音接口与新实验保存／恢复的连接，不是语言模型的理解质量或真人听感。真实头显、麦克风、扬声器和人工确认仍待验收。

## 恢复检查

第一组真实语音联调使用三个独立 Unity 进程，共 62 个运行检查点。Unity 退出后强制终止测试后端，再由相同数据库启动新后端进程。

1. **对话操作已完成但回执丢失**：故意丢弃一次分支设置请求的响应；客户端保留原请求，查询已落盘回执并刷新实际执行状态，没有重新应用设置或发起模型调用。
2. **问卷提交已完成但回执丢失**：后端已提交四策略问卷，客户端没有收到确认时不切题，原提交包保持 pending。Unity 和后端重新启动后按原 request_id 恢复，第一题仍只有四份最终记录，只打开一个下一题。
3. **未提交本地草稿**：第二题只填两项，退出 Unity 并重启后端；恢复后本地值仍在，后端仍明确为 unanswered，未把本地草稿伪装成服务器最终提交。补完其余项才允许继续。
4. **明确中止**：两题后提前结束，最终导出只有已提交的 8 份属性反馈；其余任务及模块保留未完成状态，export_status=partial。提供的本地 journal 副本核对通过。
5. **自然反馈重启恢复**：另一个缩小前置任务的工程 fixture 建立自然模块，完成真实 STT/TTS 后保存 26 题，再强制重启后端。答案保持不变，之后提交一份自然反馈并正常结束。
6. **未知在途操作**：后端专项测试确认，只有已提交回执才能核对；没有回执或处理未完成时继续保留未知状态，禁止自动重放模型请求，不把未知结果记成成功／失败评分。

自然段检查由 HTTP 驱动，没有提供该运行的 Unity journal 副本，因而其 export_status 保持 **unreconciled**；这准确表示未做客户端副本核对，不应写成完整双端验证。它的前置工程任务数也不等于正式 32 题设计。

第二组断线补测使用纯本地语音 fixture，不读取语音密钥、不产生新增云调用；证据在 `run-02-offline/`。在暂停请求发送之前停止后端，验证本地 pending、交互锁定、重启后的原请求提交和显式 Resume。本组 68 个 Unity 运行检查点全部通过、云调用为 0；两组共 130 个 Unity 检查点。汇总见 `StudyData/validation/study-speech-recovery-20261116/summary.json`。两组的部分运行导出均准确标为 partial，本地副本核对通过。

## 本次修复

- 新增 `/study/runs/<run_id>/runtime-receipt` 只读核对入口：核对运行、执行器、原 operation、原 request_id 及完整请求签名，读取已有持久回执，不执行模型调用。
- 恢复时先核对本地未确认的对话操作，再重新读取实际执行器。相同 runtime_id 也要刷新，避免复用断线前的内存界面。
- 数据有待同步操作或本地写盘故障时，锁定新的 tutor 交互；请求未到达后端时也不能继续假装已经暂停／保存。
- 研究审计检查点串行更新；补录播放事件只推进审计偏移，不把较旧执行器快照写回覆盖新状态。播放上报被接收后立即并入研究事件。
- 原有未完成／最终提交、问卷版本、属性任务材料及正式采集限制不变。

## 验证与运行入口

- `Backend/tests/test_study_flow.py`：9 项桥接专项测试通过。
- 完整后端回归：464 项通过，见同目录 `backend-tests.log`。
- `TutorStudyRecoveryChecks.cs`：Editor 专用自动检查组件，不进入 Android Player；只调用带标签的合成音频入口，不调用 Microphone.Start。
- `Tools/AppearanceExperiment/verify_study_speech_recovery.py`：自动运行、重启、导出及核对。默认不允许云调用，需显式 `--execute-speech`；跨后端重启的调用账本分别限制最多 4 次 ASR 和 4 次 TTS。`--fixture-speech` 完全离线模拟语音并增加断线故障。
- 测试输出目录必须是新目录，旧证据不会被覆盖。不要为了重新看结果而重复执行真实 API 检查。

批处理 Unity 日志中有既有 XR Device Simulator 在无物理设备环境下初始化 UI 的越界异常，发生在检查组件启动之前；本轮未修改该样例插件，也未把它算作 VR 设备验收通过。已完成的应用侧流程检查及编译结果见各阶段报告。
