# 外观方向：四类情境建议

> **历史设计/阶段记录；导航更新于2026-11-28：不作为当前施测说明。** 当前研究为四属性＋外观40题，五模块均采用四策略并行及模块末20项评分＋多选偏好；自然情境仅用于demo。请先读[当前主设计](FINAL_USER_STUDY_DESIGN_4_STRATEGIES.md)、[40题任务库](CURRENT_TASK_BANK_40.md)、[当前问卷与数据规范](CURRENT_QUESTIONNAIRE_AND_DATA_CONTRACT.md)。下文各日期中的“当前”“最新”仅指当时阶段，保留历史讨论与旧实现，不恢复旧自然问卷、三策略或60题流程。

2026-11-05，v0.1。五方向轮次、每情境三任务是用户最新规划；以下外观情境划分为待确认建议，尚未定稿十二张任务卡。

## 1. 结构与维度

实验按 speech rate、reply length、tone、voice、appearance 五个方向组织成五轮；每方向暂按四类情境，每情境三道不同目标任务，每轮十二题、总计六十题。每题三策略使用同一初始请求并行、自由比较，不另做 E/A/S 匹配题目变体；六十题包含一百八十个策略体验/评价单元，不称一百八十道独立任务。

每题完成对应结果/过程问卷后 Next question；每方向结束选该方向偏好；全部结束选总体偏好。按最新描述，不默认额外增加每题策略偏好；题内 T1/T2 仍分别评价三策略。原 B1–B5 是否在方向/整体结束保留另议，不能自动在每方向重复十五题。VR 后访谈整体可选，用于报告或 presentation 的局限性、未来方向及具体体验补充。

外观情境宜按请求与决策问题划分；颜色、配饰、比例、服装是任务作用对象，不直接替代四类情境。这样可以在外观中继续观察何时直接做、何时询问、如何利用历史，避免只比较四种外观控件。

## 2. 推荐的四类情境

| 类别 | 核心特征 | 设计示例（不是必读脚本） | 主要观察 |
| --- | --- | --- | --- |
| A1 明确目标的定向修改 | 目标属性和值或操作明确；可带明确保持要求 | 衣服改为绿色，眼镜和大小保持 | 对明确请求的执行、额外确认体验和修改范围 |
| A2 程度不精确的小幅调整 | 修改方向明确，幅度未精确；先用已有整体比例能力 | 希望角色比现在稍微大一点，其他外观保持 | 小步试改、是否需要量化澄清、用户对幅度的接受与修复体验 |
| A3 多种可行解释的风格/整体印象调整 | 同一目标描述可能对应不同属性或候选结果 | 希望外观更休闲，可能换运动服或改变配饰 | 是否识别真正有意义的解释差别、澄清是否有帮助及结果是否符合私有目标 |
| A4 历史引用与选择性恢复 | 请求需要利用历史或已有偏好，并限定恢复范围 | 恢复之前的衣服颜色，但保留刚加上的帽子 | 历史理解、局部恢复、避免恢复整套外观或覆盖保留内容 |

A1 不是只能改一个字段，明确的多字段请求也可属于该类；需避免把修改属性数与策略绑定。A2 与 A3 的区别是主要不确定性来自幅度还是不同实质解释，二者可以有重叠，主要标签按设计预先确定。

A4 不全部设置为歧义：十二题进一步设计时，可在该类三题中考虑唯一历史引用、多种历史引用、局部恢复/明确覆盖软偏好，具体三题待确认。参与者表达充分时可能直接说出目标值，不要求其故意含糊；同时记录设计类型与实际表达。

## 3. 与当前能力的对应

已核对 Backend/capabilities.py：扩展能力有 Liang 的 suit/sport/none、离散颜色、none/hat/glasses 配饰、0.85–1.15 且步长 0.05 的整体比例，以及 Liang/Nailong 身份。扩展 profile 仍为 debug；正式研究配置需后续实现，但本轮只规划题目。

A1 可在颜色、配饰、服装上分布；A2 优先使用整体比例，因为当前颜色没有连续明度/饱和度，配饰/声音也没有天然连续幅度。用‘整体大小’比独立身高更贴近等比例缩放能力。不把‘颜色更浅一点’写成已支持能力。

A3 只能使用资源确实能实现且语义合理的候选；更休闲与换运动服/配饰的对应尚需核实，不预设所有人都认同去眼镜更休闲。如果自由表达已明确目标，不按设计标签强制要求 S 提问。

A4 使用公开可见的历史，不把模型不知道的私有任务卡当作可用记忆；恢复某字段后保留其他字段的最新变化。

建议第一版主要在同一角色上完成颜色/配饰/比例/服装任务，保持任务可比。身份切换可作为 A1/A3 的扩展内容，但不是必需的第五情境；跨角色默认外观与风格差异需单独定义，不默认塞入十二题。

## 4. 确认四类后再写每类三任务

每个任务写明：英文目标卡、相同起始状态、目标范围/保持要求、公开历史、可选例句以及参与者需要看/听什么。无需为同一目标再写三套策略变体；三个策略共用一次自然表达。三个任务应有不同目标或上下文，不仅把同一例句换个说法。

结果由问卷判断，不另做客观音频评分；修改范围和目标帮助参与者评价，不构造未授权的强制后台正确率指标。总体计时/pilot 仍按用户要求实现后再谈，当前不因此删减题量。
