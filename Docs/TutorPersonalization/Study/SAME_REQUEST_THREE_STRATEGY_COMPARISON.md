# 同一自然请求的三策略自由比较：当前主实验设计

> **历史设计/阶段记录；导航更新于2026-11-28：不作为当前施测说明。** 当前研究为四属性＋外观40题，五模块均采用四策略并行及模块末20项评分＋多选偏好；自然情境仅用于demo。请先读[当前主设计](FINAL_USER_STUDY_DESIGN_4_STRATEGIES.md)、[40题任务库](CURRENT_TASK_BANK_40.md)、[当前问卷与数据规范](CURRENT_QUESTIONNAIRE_AND_DATA_CONTRACT.md)。下文各日期中的“当前”“最新”仅指当时阶段，保留历史讨论与旧实现，不恢复旧自然问卷、三策略或60题流程。

## 1. 已确认的实验单元

研究者给定一个情境/目标 → 用户自由口述一次 → 一次 STT 的同一文本送入三份相同公开起始状态 → E/A/S 并行处理 → 用户自由切换、查看/试听、回答澄清及修复 → 对三策略填写本题反馈 → 点击 Next question。

不再使用 EAS 等六序列指定参与者依次体验分支。没有额外的 Finish adjustment / End attempt / Success 按钮，不把 Next question 当作成功声明。进入下一情境前必须填写本题对应问卷；原因和描述仍为可选，不能强制口述。

每个小部分结束后选择该部分偏好，全部完成后选择总体偏好。访谈整体为可选补充，不影响主实验完成。模块划分建议为 speech rate、reply length、tone、voice、appearance 五部分，具体顺序、外观是否细分待讨论，不因取消策略顺序而声称题目/属性顺序无影响。

## 2. 并行处理和自由比较的具体含义

三个分支使用相同初始请求、公开上下文和基线，各有独立状态/历史。公共模型、解释候选、能力与参数尽可能一致，仅政策门控不同。私有目标不传入模型；后续某分支的澄清回答不自动广播给其他分支。

三策略卡片可以同时可见，用户自行选择要交互、播放或查看的策略，没有系统强制的先后顺序。语音一次播放一个分支，避免音频重叠；用户可暂停、切换、重新听。外观可按当前布局切换预览或在相同条件下并列展示，具体布局待设计；不能把三分支变更叠加到同一份状态。

A/S 若需要澄清，应明确显示等待用户回答，用户选择该卡后自由口述，不能将问题本身伪装为已完成结果，也不能由后台用私有目标替答。每次话语明确路由到用户选中的分支。再次查看某分支恢复该分支自己的最新状态；只在新情境开始时三分支重置到新的共同基线，不能每次切换都丢掉已有修复。

状态可为等待澄清、处理中、结果可查看、无法继续等，不以‘已完成’暗示达标。结果相同也保留三分支，允许无偏好；不重生成到出现差异。

后台同时处理不等于用户没有先后暴露；界面位置、率先准备好或先点击的方案仍可能影响选择。**建议**在不同参与者间平衡卡片位置，记录实际点击/播放路径；不在同一题的重看过程中移动卡片。稳定策略名称/标识与位置分开，策略说明在开始比较时呈现，不默认标为盲测。位置平衡尚未作为用户批准的具体分配方案。

## 3. 反复比较与问卷联动

用户可以先比较后填写，也可以在本题未提交时回到结果、继续查看并改答案。Next question 仅在核心结构题已作答且记录可保存时用于提交并前进；没有额外任务完成确认。

推荐本题问卷构成：每策略 T1 感知达标、T2 过程顺利，共六个答案；加本情境偏好一个答案（沿用上轮提议）。原因及 STT 备注按需要提供，不作为前进条件。确切本情境偏好是否必答可随最终界面冻结，但不能自行删除已经规划的本题比较。

无法判断/无法比较是有效回答，可以满足问卷要求，不强迫参与者填达标或编造评分；空白不是有效回答。退出/暂停独立可用，不要求作答后才允许停止参加。未完成澄清者可以如实评价未达标/无法判断并结束本题，记录分支实际状态，不强迫先成功或完成无意义对话。

仅重播/重看同一结果，不清空已有答案。若澄清或修复改变某分支的结果/交互，应提示重新评价该分支已有评分及本情境偏好，其他分支答案保留；不能把旧评分默默绑定新结果。具体确认方式待 UI 设计，不能另造一个必须声称任务成功的步骤。

Next question 提交时将答案与当前分支状态版本一并冻结；离开后停止/隔离尚未完成的生成，不能让迟到结果覆盖已评状态。自动保存、重复点击和中断恢复可提前用模拟数据测试，不需要先接完模型。

评分含义仍为参与者感知；不从提交按钮、填写完整或已显示输出自动生成客观成功。

## 4. 分层偏好与原问卷迁移

| 层级 | 内容 | 当前地位 |
| --- | --- | --- |
| 情境内策略反馈 | 三策略各回答 T1/T2，原因/STT 可选 | 沿用认可题项，改为同题内可反复比较后提交 |
| 情境偏好 | 对刚才这条需求，更愿意采用哪一种处理方式？ | 沿用上一轮设计建议；必答细节待正式界面确认 |
| 小部分偏好 | 如‘在刚才的语速调整任务中，你更偏好哪种处理方式？’ | 用户新增并确认要收集；每属性部分结束后填写 |
| 整体偏好 | 全部任务后的整体偏好，保留必要的领域比较 | 用户确认保留；已收集外观模块偏好与最后外观题是否复用待简化 |
| 五项体验 B1–B5 | 打断、控制、努力、满意、询问/执行合适 | 题项仍有价值，原分轮时点作废；建议全部比较结束后按策略各答一次，不在每个小部分重复 15 题；待用户确认 |
| 访谈 | 偏好理由、具体案例、优先改进 | 整体可选，只作定性补充/未来方向线索，拒绝或未做不算研究未完成 |

偏好题使用稳定策略标识而非‘第几轮’，允许一项、两项并列、无明显偏好、都不愿用、无法比较。核心偏好需填写时后三项均有效，开放理由不必填。具体英文题干在新问卷施测版统一准备。

小部分偏好可能不同于逐题多数票和全局偏好；分别保留，不能自动替用户汇总或强制一致。不因一个用户填写多情境、多模块就当作多个独立参与者。

## 5. 研究结论与时间边界

该设计比较的是用户自由切换三种处理方式时的感知结果、过程体验与偏好，不是独立使用某策略的一段完整连续对话。自由切换本身可能缓解等待或改变打断感，B1 等解释必须对应当前实验环境。

取消预分配顺序符合当前自由比较设计，但不证明没有位置、记忆和学习影响。[Ho & Min (2025，预印本)](https://arxiv.org/abs/2505.03937) 对被试内比较的迁移假设提供方法讨论。该来源不为某个具体界面或顺序方案背书。

可减少重复输入和部分后台等待，但反复比较和每分支评分仍占用时间，不能承诺一定缩短为三分之一。用户要求实现后再讨论整体预实验；问卷分支、必答校验、STT 文本路由、状态关联和日志可以先用模拟数据测试。

本轮仅更新设计材料，不实现界面、不录音、不调用模型、不运行用户研究。
