# 左侧任务／问卷面板：尺寸与风格

更新：2026-11-26。应用于当前 `TutorComparisonDesktop/VR` 研究流程的 `TutorStudyFlowPanel`，不修改历史旧版问卷组件或题目。

- 任务说明、交流提示、开始/暂停/结束页使用 780×780 画布；相对原 920×1050 的面积约为 63%。
- 四属性与自然模拟问卷、策略偏好、可选原因及口述备注页面使用 920×1050 画布，保留原评分控件尺寸。
- 底边位置固定，面板向上展开；不重置参与者拖动后的位置。隐藏时仅剩 250×52 的 Show panel 按钮，按钮保持在隐藏前的位置；重新打开按当前内容恢复尺寸。
- 使用与右侧同一暖色玻璃 shader、柔光、圆角按钮和暖白文字。问卷背景比任务页略深，便于区分评分内容。选中项使用暖色高亮及粗体。
- 长任务说明保持字号，通过滚动或上下箭头查看；同一任务刷新和隐藏/显示时保留阅读位置，新任务回到顶部。
- 任务内容、问卷题干、评分、保存/提交规则和模式约束未改变。

## 本机验证

使用独立 8781 mock 服务及 `StudyData/validation/left-panel-20261126/`，未调用付费模型，未使用既有参与者数据。

已检查任务卡、自然模拟引导的界面预览和实际执行器绑定后的四属性问卷；验证两种尺寸的隐藏/恢复、固定底边、鼠标拖动及桌面下限、展开时保留位置、长说明刷新后保留滚动位置。四属性问卷固定文字未发现高度裁切；Unity 编译和控制台无错误。

截图保存在上述本机验证目录。自然模拟引导使用仅影响内存界面的预览，不是完成自然实验的数据；本轮没有重跑整个自然会话或 32 题流程，也没有进行头显实测。
