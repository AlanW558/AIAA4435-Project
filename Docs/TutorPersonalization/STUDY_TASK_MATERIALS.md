## 固定起点与示例上下文

普通研究起点为 rate=1.00、Balanced、Professional、Voice A；每题按已确认表格覆盖。应用普通会话的默认 Voice D 未改变。

- R1-1 与 R1-2 均从 1.20 开始，分别要求默认语速的 90% 和当前语速降低 10%；不能先自由调起点。
- C4 通过真实状态历史结构记录旧值和当前值。R4-1 单一旧语速、L4-2 多历史结构、L4-3 局部结构恢复、T4-1 历史风格、V4-2 多历史声音、V4-3 声音局部恢复均独立装载。
- R4-3 / T4-3 装载明确标注的示例旧软偏好。它们是可覆盖的偏好，不是强约束。
- 每题附同一学习主题的示例问题 “How can active recall help me study?”。Brief 只给关键点，Balanced 加简短理由，Detailed 再加例子；风格示例按对应 tone 编写。C4 的不同历史条目配各自例子。这些是研究者编写的材料，不是参与者的真实历史或预先生成的策略结果。
- 任务卡明确标注 supplied example context；私有目标优先显示，长上下文可滚动。每题重新建立独立起点，不继承上一题实际结果。
- 研究预演的准备界面允许听当前固定样例、查看任务说明，然后 Confirm settings；四项设置控件禁用。后端也拒绝 `prepare`，不能通过绕过前端改起点。
- 确认只确认既定起点，不代表任务完成。确认后仍由参与者录制并提交一个真实请求；各分支澄清完成后统一揭示。

## Voice 材料和文案修正

维持现有 A–E 音色映射及 Voice D 应用默认值。V2/V3 不再预设 Voice B 必然温柔、Voice C 必然低沉，改为听对应目标样例后自由描述希望的声音；可以直接说字母，不强迫制造歧义。

- V1-1 / V2-1 / V3-1：目标 B；V1-2 / V2-2：目标 C；V3-2：目标 A。
- V4-2：三个可重听条目 B → C → A。V4-3：旧 B（0.90、Professional）与当前 A（1.15、Friendly）。
- 左侧实验面板任务页提供最多三个 Play 按钮。V1–V3 可听起点和目标，V4 可听历史。使用同一个短句；保持相应题目/条目的 rate 与 tone，后端从登记材料解析声音，不接受客户端任意文本或设置。
- 试听不更改 tutor 当前状态、不增加参与者/tutor 对话，也不替任何策略回答澄清。澄清及隐藏结果期间不可请求材料音频；暂停、退出、切题或页面隐藏后停止或丢弃迟到音频。
- `purpose=material`，`exchange_id` 为当前题的 1 起始材料索引，沿用原音频请求和播放审计。`settings_scope=study_material` 区分研究材料与分支回答。这里只调用 TTS；目标说明不进入对话模型。

正式使用前仍需真实试听核验声音可辨性、目标表达是否清楚，以及中性文案是否能充分区分 C2 的定性偏好和 C3 的跨属性竞争解释。本次工程模拟不能证明这些研究效度，也不评判任务是否实际达标；任务评价仍由参与者填写。

## 版本与流程保护

Unity 传输白名单仅包含 task_code/domain/scenario 和序列元数据。预演附材料版本及整个资源文件的 SHA-256；后端从自己的相同文件读取起点。版本或文件不一致时拒绝启动，不静默退回练习。修改材料后须重新载入 Unity 并重启后端。独立部署后端时必须同时部署该资源文件，保持项目相对路径。
