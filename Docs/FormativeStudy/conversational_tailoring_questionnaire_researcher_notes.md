# Conversational Tailoring Questionnaire — 组内使用说明

**版本：**修订稿 v2，2026-09-12  
**配套问卷：**`conversational_tailoring_questionnaire_revised.md`  
**状态：**已完成内容修订；尚未经目标受访者预测试，也不是经过验证的标准量表。  
**用途：**AIAA4435 Week 2 formative study。本文件只供小组使用，不放进受访者问卷。

## 1. 题目数量与范围

保留 **12 个编号问题：10 道选择题＋2 道可选短答**。不使用大矩阵、不要求逐题说明理由，也不要求填写额外人口统计资料。各题的 “Other” 允许选择后不填写解释。

A 保留为总体使用背景与经历；B、C、D 分别对应三个 RQ。Q12 是全局补充题，放在问卷末尾，而非增加第五个正式分类。

本次用“在 VR 中通过说话调整虚拟语言导师”作为统一想象情境，聚焦交流风格、声音和行为。它不是对 role、goal、personality、appearance 四个维度的全面评价。

## 2. 题目与研究问题的对应

以下是三个 RQ 在本次问卷中的可测部分，不等同于模型内部机制诊断。

| 部分 / 题号 | 本次收集什么 | 证据类型 |
|---|---|---|
| A / Q1 | 是否有通过语言调整 AI 后续回复的经历，以及输入方式 | 自报背景；不是 VR 熟练度或提示词专业能力 |
| A / Q2 | 最近一次尝试的目标与结果；允许成功、失败及探索性经历 | 回忆性叙述 |
| B / Q3 | 表达需求时最突出的困难：确定目标、措辞、能力边界、上下文 | 最近一次尝试中的自报困难 |
| B / Q4 | 执行前希望核对的解释内容：目标、修改对象、程度、持续范围、保持不变的部分 | 情境偏好 |
| B / Q5 | 在可撤销修改和一次额外交流的条件下，对澄清或直接尝试的选择 | 条件化策略偏好 |
| C / Q6 | 简单语速修改、无等待反馈时，自报可接受的最长等待范围 | 预期容忍度；不是实测阈值 |
| C / Q7 | 相同五秒等待下，对语音、视觉、两者或无提示的偏好 | 等待反馈偏好；不是效果比较 |
| C / Q8 | 同一次会话中已明确约定的偏好失效，预期会造成多大中断 | 单题情境化影响评分 |
| D / Q9 | 最依赖哪类信息或体验判断修改是否符合要求 | 验证依据偏好；不是实际验证能力 |
| D / Q10 | 精确选项不可用时，对预览、确认、替代执行或保持原状的选择 | 近似匹配的处理偏好 |
| D / Q11 | 出现非预期附带修改时，希望怎样修复、接受或停止调整 | 纠错与恢复偏好 |
| 全局 / Q12 | 最重视的因素、理由，以及问卷未覆盖的需求 | 开放补充；不预设只能出现三个 RQ |

**RQ1：**用户表达修改需求时遇到什么困难？他们希望怎样核对或澄清系统的解释？  
**RQ2：**等待与同一会话内偏好失效预期会怎样影响交流？用户偏好什么等待反馈？  
**RQ3：**用户希望怎样检查修改结果、处理不能精确满足的要求，以及修复不匹配？

## 3. 发放与跳题设置

- Q1 选择前三个 “Yes” 选项：显示 Q2（可选）和 Q3，再显示共同情境与 Q4–Q12。即使跳过 Q2，Q3 仍回答最近一次尝试。
- Q1 选择 “No” 或 “Not sure”：隐藏 Q2、Q3，直接显示共同情境与 Q4–Q12。Q1 留空时也走此路线，不替受访者假定使用经历。
- 因此，完整路线显示 12 题；无明确相关经历的路线显示 10 题。Q2、Q12 都不强制回答，其他题也允许跳过。
- Q3、Q4 为“最多选两项”，不是必须选两项。“Nothing was difficult”／“No check beforehand”以及无法判断类选项须独占，不能与其他选项并选。其余选择题均为单选。
- 有序时间范围与 Q8 的程度选项保持从低到高；无序选项可随机呈现，但将 “Other”、无困难／无需核对、无偏好、无法判断放在末尾。整个研究使用同一设置并记录版本。
- 原问卷的通用 0–5 重要性量尺已删除。Q8 的五级文字程度量尺只适用于该题。不要在平台上为其他题自动添加重要性量尺。
- 保留“可跳过、可退出、无标准答案”的说明。按课程要求补充实际数据用途、访问范围与保存安排；没有确认平台设置前，不承诺完全匿名，也不声称已获伦理审批。关闭不必要的姓名、邮箱收集，不公开原始回答。

所有受访者都阅读同一共同情境。不在发放前告诉他们“我们的系统理解差、容易遗忘、用户会烦躁”。Q5–Q11 描述的是特定假想情况，不是在暗示这些是所有 AI 或原系统的实际表现。

## 4. 如何分析而不夸大

**先分开真实经历与想象偏好。**Q1–Q3 是自报经历，Q4–Q11 是假想情境回答。Q12 根据内容标记是具体回忆、情境看法还是一般期待；不能自动当作真实使用证据。

**选择题逐题汇总。**报告选项人数、该题作答人数，以及跳过／未展示人数。默认分布的分母是该题作答人数，“无法判断”与“无偏好”也作为回答保留；若另报“有明确偏好者中的比例”，单独标明排除了哪些回答及剩余人数。Q3、Q4 同样以该题作答人数为分母，并说明可多选，合计可能超过 100%；选中率反映“被列为较突出或优先的内容”，不是问题出现频率。

**不要制造总分。**这些题混合名义选择、时间区间和程度评分，不能平均成 RQ 分数、满意度总分或“体验指数”。Q6 报告区间分布，不以区间中点或选项编号计算精确平均秒数；“8 秒或更久”没有固定上限。Q8 可按 1–5 编码展示有序分布，但它只测一个假设情境下的预期中断程度。

**保留不同含义。**“没有困难”“不需要核对”“无偏好”“无法判断”、主动跳过与因路由未展示，分别记录。Q6 的等待上限与 Q7 在五秒等待下的反馈选择并不矛盾：用户即使不接受五秒等待，仍可回答在该条件下偏好何种提示。

**开放回答用于发现问题，不只验证既定 RQ。**整理“目标—尝试—结果—后续反应”中实际被提到的内容，允许出现新主题、成功经历和反例。不要把用户主动探索偏好等同于被迫纠错；没有提到的细节不要补写。可用去标识化短引文支持发现，但不要把一次提及报告为普遍现象。

**结论限于证据。**可以说“在该情境下，受访者更偏好先试听替代声音”；不能说“试听提高了匹配准确率”。问卷无法定位错误究竟发生在语言理解、属性映射还是执行阶段，也不能证明某种提示改善实际沉浸、满意度或系统延迟。

## 5. 预测试：先检查理解和负担，再确定填写时长

建议先让 2–3 名目标受访者独立试填，记录自然填写时间，再简短询问哪里难懂、重复或难以选择。不要把事后的解释讨论时间算进填写时间。

重点核查：Q1 是否被理解为调整后续回复而非普通问答；Q5 的两种解释与一次额外交流是否清楚；Q6 的等待起止点、Q7 的固定等待时间是否明确；Q8 是否被理解为同一次会话，而非跨天记忆。

这份修订稿没有预先宣称“几分钟一定填完”。时间说明应依据预测试再添加。若负担仍明显偏高，先精简题干和选项；确实需要删题时，可将 Q4 的执行前核对内容转移到后续访谈。不要为了追求题数少而把几道不同问题藏进一个矩阵。

预测试后冻结一个发放版本。若中途必须修改，记录版本并检查答案能否合并；预测试回答不自动并入正式结果。

本稿是为本课程任务自行修订的形成性问卷，题目不是原论文或其他论文的标准化测量工具。

- Week 2：`Formative Study.pdf`，**c / User Research Methods**，pp.25–28、37–38：明确题意、减少引导、结合题型、精简负担，以及反思问题能否提取痛点；**e / User Journey Map**，p.62：关注需求形成、情绪与预期不匹配；p.82：初步反馈用于形成新方向，而非预先证明方案有效。
- Bellucci et al., *Immersive Tailoring of Embodied Agents Using Large Language Models*, IEEE VR 2025，§6.2–7（PDF pp.6–7）：延迟、定制结果不稳定、提示表达与理解反馈困难，以及更丰富上下文与纵向记忆的需求。Q8 的同会话情境是本次研究设计，不是宣称原论文已确认“上下文窗口太短”或测得特定遗忘率。
